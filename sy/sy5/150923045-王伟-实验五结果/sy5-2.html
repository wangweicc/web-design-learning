EditPlus 简介

EditPlus 是 Windows 下的一个文本编辑器、HTML 编辑器、PHP 编辑器以及 Java 编辑器。它不仅是记事本的一个很好的代替工具，同时它也为网页作者和程序设计员提供了许多强大的功能。

对 HTML、PHP、Java、C/C++、CSS、ASP、Perl、JavaScript 和 VBScript 的语法突出显示。同时，根据自定义语法文件它能够扩展支持其它程序语言。无须网络浏览器预览 HTML 页面，以及 FTP命令上传本地文件到 FTP 服务器。

其它功能包括 HTML 工具栏、用户工具栏、行号、标尺、URL 突出显示、自动完成、素材文本、列选择、强大的搜索和替换、多重撤销/重做、拼写检查、自定义快捷键，以及更多其他功能。
